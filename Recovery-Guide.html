Ty Recovery USB

Choose the system you want to recover. This offline guide works without Python or administrator access.

This is a recovery assistant, not bootable installation media. It cannot detect hardware from your browser or reset a computer automatically. Back up files before choosing an erase operation in the official tools.

Recovery routes

Windows PC

Use Reset this PC in Windows Recovery settings. Choose keep files or remove everything in the official wizard. A clean install is different from restoring the original OEM factory image. Back up files and retain your BitLocker recovery key first.

Official recovery instructions

Microsoft Surface

For original factory recovery, obtain the exact Surface recovery image from Microsoft using the device serial number. ARM and Intel Surface images are different. The Windows reset wizard is also available for supported working installations.

Official recovery instructions

Mac — Apple silicon

Shut down. Hold the power button until startup options appear, choose Options, then Continue. Use macOS Recovery to repair or reinstall. Reinstalling alone does not erase personal files; erasing is a separate deliberate action. Credentials or the previous Apple Account may be required. A generic PC recovery ISO cannot substitute for Apple Recovery.

Official recovery instructions

Mac — Intel

Shut down. Start up and immediately hold Command-R to enter macOS Recovery. If built-in recovery fails, consult Apple Internet Recovery instructions. Reinstalling alone does not erase personal files. External boot availability depends on the Mac and its startup security settings.

Official recovery instructions

Chromebook / ChromeOS

For a working device, use the official factory reset (Powerwash) workflow. For a damaged OS, use Google recovery instructions and an image matching the exact model or board shown on the recovery screen. Many Chromebooks enter recovery with Esc + Refresh + Power; tablets and other models differ. Some support internet recovery. USB recovery creation overwrites the USB; use a separate drive from this toolkit. Managed devices require the administrator.

Official recovery instructions

Ubuntu Linux

Use the official Ubuntu installation guide and an image compatible with the hardware architecture. Write the image using an image writer on a separate USB, boot it using the device boot menu, and try the live environment to check hardware first. Reinstallation and disk erasure are chosen in the installer. A Linux reinstall is not an OEM factory restore.

Official recovery instructions

Other Linux distributions

Detection reports the currently running distribution only. Obtain the installation or OEM recovery image from that distribution or manufacturer and verify architecture, signatures and hardware support. Do not substitute an Ubuntu image for the original OS without choosing to change distributions. No universal Linux factory-reset command exists.

Unknown / unsupported system

No compatible recovery route has been established. Identify the exact manufacturer, model and original OS using labels or official support before proceeding. Do not erase or guess an image.

Using detection

Windows: launch Start-Recovery.cmd. Mac or Linux: run sh Start-Recovery.sh from this folder. Python 3 enables local detection; otherwise open this guide and choose manually. ChromeOS: open this file in Files; no developer mode is needed.

If the computer cannot start

Use another working computer to prepare the correct official recovery media. This guide and its scripts do not boot by themselves. Windows/Linux multiboot media, Apple Recovery and model-specific ChromeOS recovery are separate paths. Writing an image may erase an entire USB drive, including this toolkit.
